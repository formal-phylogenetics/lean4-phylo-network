# PhyloNetwork

The library of this hub: the definitions and results that two or more papers on network estimation
use, and that the root library [lean4-phylogenetics](https://github.com/vltanh/lean4-phylogenetics)
does not hold. Each goes to the lowest hub that holds every repository that uses it: a result that
one paper uses stays in that paper's repository; one that papers of several hubs use goes to the
root library.

Its modules are `PhyloNetwork.*`, in the namespace `PhyloNetwork`, and import only Mathlib,
`Phylogenetics` and this library. It has none yet.
